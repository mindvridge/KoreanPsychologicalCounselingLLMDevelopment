========================================
마음챗 Windows 실행파일 빌드 및 사용 가이드
========================================

[빌드 방법]
-----------
1. build_exe.bat 파일을 더블클릭하거나
2. 명령줄에서 실행: build_exe.bat

빌드가 완료되면 dist/마음챗.exe 파일이 생성됩니다.

[실행 방법]
-----------
생성된 dist/마음챗.exe 파일을 더블클릭하세요.

[실행 파일의 기능]
-----------------
마음챗.exe를 실행하면 start_all.py와 동일하게 작동합니다:

✓ 기존 서버 프로세스 자동 종료
  - 포트 8000 (메인 API 서버)
  - 포트 8001 (음성 API 서버)

✓ 서버 자동 시작
  - 메인 API 서버: http://localhost:8000
  - 음성 API 서버: http://localhost:8001

✓ 브라우저 자동 열기
  - http://localhost:8000

✓ 모든 초기화 과정 수행
  - LLM 초기화
  - TTS/STT 모델 로드
  - 데이터베이스 연결
  - 기타 시스템 초기화

[주의사항]
----------
1. .env 파일이 필요합니다 (API 키 등)
2. espeak-ng가 설치되어 있어야 합니다
3. CUDA가 설치되어 있어야 GPU를 사용할 수 있습니다
4. 실행파일과 같은 폴더에 configs, frontend 등 데이터 폴더가 포함되어 있습니다

[문제 해결]
----------
- 실행이 안 되면: 관리자 권한으로 실행 시도
- 오류 발생 시: 콘솔 창의 오류 메시지 확인
- 포트 충돌: 기존 서버를 수동으로 종료 후 재시도
