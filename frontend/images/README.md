# 이미지 파일 안내

이 폴더에는 다음 이미지 파일들이 필요합니다:

## 필요한 이미지 파일

### 1. `logo.png`
- **용도**: 마음챗 로고
- **위치**: 헤더의 로고 영역
- **권장 크기**: 200x60px (비율 유지)
- **형식**: PNG (투명 배경 권장)

### 2. `counselor_avatar.png`
- **용도**: 한국 40대 여성 상담사 아바타 이미지
- **위치**: 
  - 채팅 화면의 상담사 아바타
  - 홈 화면의 시작 아이콘
  - 음성 채팅 화면의 상담사 아바타
- **권장 크기**: 400x400px (정사각형)
- **형식**: PNG (투명 배경 또는 자연스러운 배경)
- **스타일**: 
  - 한국 40대 여성 상담사 이미지
  - 전문적이고 따뜻한 인상
  - 원형으로 표시됨

## 이미지 추가 방법

1. 위의 이미지 파일들을 준비합니다.
2. 이 폴더(`frontend/images/`)에 파일을 복사합니다.
3. 파일명이 정확히 일치하는지 확인합니다:
   - `logo.png`
   - `counselor_avatar.png`

## 이미지가 없을 경우

이미지 파일이 없으면 기본 이모지(🧠)가 표시됩니다.

## 이미지 최적화 팁

- 파일 크기를 최소화하여 로딩 속도를 개선하세요.
- PNG 형식 사용 시 투명 배경을 활용하세요.
- WebP 형식도 지원됩니다 (더 작은 파일 크기).
