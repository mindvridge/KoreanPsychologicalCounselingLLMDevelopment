# 로고 이미지 저장 안내

## 첨부하신 이미지 저장 방법

첨부하신 "마브 MINDBRIDGE" 로고 이미지를 다음 경로에 저장해주세요:

**파일 경로**: `frontend/images/logo.png`

## 저장 단계

1. 첨부하신 이미지 파일을 확인합니다.
2. 이미지 파일을 `frontend/images/` 폴더에 복사합니다.
3. 파일명을 `logo.png`로 변경합니다.
4. 웹 브라우저를 새로고침하면 로고가 표시됩니다.

## 이미지 요구사항

- **파일명**: `logo.png`
- **위치**: `frontend/images/logo.png`
- **권장 크기**: 200x60px (비율 유지)
- **형식**: PNG (투명 배경 권장)

## 확인 방법

이미지를 저장한 후:
1. 서버를 재시작합니다 (필요한 경우)
2. 브라우저에서 `http://localhost:8000` 접속
3. 헤더의 로고 영역에 이미지가 표시되는지 확인

## 참고

- 이미지 파일이 없으면 기본 텍스트 "마음챗"이 표시됩니다.
- 이미지 로드 실패 시에도 기본 텍스트가 표시됩니다.
