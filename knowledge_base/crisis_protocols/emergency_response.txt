# 응급 상황 대응 매뉴얼

## 즉시 응급 조치가 필요한 상황

### 🚨 생명 위협 상황 (LIFE-THREATENING)

**즉시 119 호출 필요:**

```
1. 자살 시도 진행 중
   - "지금 약을 먹었습니다"
   - "건물 옥상/다리에 있습니다"
   - "칼/흉기를 사용했습니다"

2. 의식 저하 또는 혼미
   - 대화 불가능
   - 반응 없음
   - 호흡 곤란

3. 심각한 자해
   - 과다 출혈
   - 깊은 상처
   - 의식 소실 위험

4. 폭력 행동
   - 자신 또는 타인에 대한 즉각적 위험
   - 무기 소지
   - 통제 불가능한 분노

5. 심각한 정신증
   - 명령 환청 ("죽어라" 등)
   - 위험한 망상
   - 현실 인식 완전 상실
```

**즉각 조치:**
```
1. 119 호출
2. 위치 명확히 전달
3. 상황 간단히 설명
4. 지시 따르기
5. 연결 유지
6. 안전 거리 확보 (폭력 시)
```

## 응급실 이송 기준

### 정신과적 응급 상황

**즉시 응급실 이송:**

```
□ 자살 시도 후
□ 높은 자살 위험 + 안전 확보 불가
□ 급성 정신증 (환각, 망상)
□ 조증 삽화 (수면 없이 활동, 과대망상, 위험 행동)
□ 심각한 불안/공황 (일상 기능 불가)
□ 섬망 (의식 혼탁 + 지남력 장애)
□ 약물 과다 복용
□ 알코올/약물 금단 증상 (경련, 환각)
□ 중증 섭식장애 (의학적 합병증)
□ 자해 후 의료 처치 필요
```

### 응급실 동반 시 준비사항

```
✓ 신분증 / 건강보험증
✓ 복용 중인 약 목록
✓ 과거 진료 기록 (있다면)
✓ 보호자 동반 (가능하면)
✓ 최근 증상 메모
✓ 자해/자살 시도 도구 (평가 위해)
```

**이유:**
```
- 낙인 두려움

- "약 먹기 싫어요"
- "미쳤다고 정신과?"
- 시간 부족
```

**대응:**
```
✓ 정상화
  "많은 분들이 도움 받아요"
  "당뇨 환자가 내과 가듯이"

✓ 교육
  "조기 치료가 효과적이에요"
  "약은 뇌 화학 불균형을 돕는 거예요"

✓ 선택권
  "상담만 받아볼 수도 있어요"
  "한 번만 가보시는 건 어때요?"

✓ 지지
  "함께 가드릴 수도 있어요"
  "제가 예약 도와드릴게요"
```

## 응급 상황 시뮬레이션

### 시나리오 1: 자살 의도 표현

```
내담자: "더 이상 살고 싶지 않아요"

❌ 잘못된 반응:
"그런 생각 하지 마세요"
"다른 사람 생각해보세요"
"시간이 약이에요"

✓ 올바른 반응:
"많이 힘드셨나봐요. 구체적으로 어떤 생각을 하셨나요?"
→ 위험 평가 진행
→ 안전 계획 수립
→ 필요시 응급 의뢰
```

## 자주 하는 질문

**Q: 언제 응급실에 보내야 하나요?**
A: 즉각적 자해/타해 위험, 급성 정신증, 의학적 합병증, 안전 확보 불가능 시.

**Q: 본인이 거부하면?**
A: 자타해 위험이 명백하면 비자의 이송 가능. 경찰 (112) 도움 요청.

**Q: 응급실에서 입원 권유를 거부하면?**
A: 자의 입원은 본인 선택. 하지만 비자의 입원 기준 충족 시 가능.

**Q: 가족이 반대하면?**
A: 생명 위험 시 비밀보장보다 생명 우선. 가족 설득 시도, 필요시 단독 결정.

**Q: 비용이 부담되는 경우?**
A: 정신건강복지센터 (무료), 건강보험 적용, 의료급여, 긴급복지 지원 안내.
