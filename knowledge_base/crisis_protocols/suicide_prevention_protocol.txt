## 위기 수준 평가 (Crisis Assessment)

### 위기 수준 분류

#### 🔴 심각 위기 (CRITICAL - Level 5)

**즉각적 위험 - 즉시 응급 조치 필요**

**지표:**
- 자살 시도 진행 중 또는 임박
- 구체적 계획 + 수단 보유 + 의도
- "지금 죽으려고 합니다", "약을 먹었어요"
- 폭력적 행동 또는 환각/망상
- 의식 저하 또는 심각한 자해 흔적

**즉각 조치:**
```
1. 911 또는 119 즉시 연락
2. 혼자 두지 않기
3. 위험한 물건 제거
4. 가족/보호자 즉시 연락
5. 응급실 동반
```

#### 🟠 높은 위기 (HIGH - Level 4)

**높은 자살 위험 - 즉각적 전문가 개입 필요**

**지표:**
- 자살 계획이 구체적
- 수단에 대한 접근 가능
- 최근 자살 시도 이력
- "오늘 밤 죽을 것 같아요", "유서 썼어요"
- 극심한 절망감 + 충동성
- 안전 확보 거부

**조치:**
```
1. 즉시 정신건강 전문가 의뢰
2. 1393 또는 1577-0199 연결
3. 가족/보호자 즉시 알림
4. 안전 계획 수립
5. 24시간 내 전문가 면담 확보
6. 수단 제거 협조
```

#### 🟡 중간 위기 (MODERATE - Level 3)

**자살 생각 있음 - 전문가 개입 권장**

**지표:**
- 자살 생각은 있으나 계획 없음
- "죽고 싶다는 생각이 들어요"
- "사라지고 싶어요"
- 과거 자살 시도 이력
- 최근 중요한 상실 경험
- 우울/불안 증상 심각

**조치:**
```
1. 안전 계약 수립
2. 48시간 내 전문가 상담 예약
3. 자살예방상담전화 (1393) 안내
4. 신뢰할 수 있는 지인에게 알리기 (동의 하에)
5. 매일 안전 확인 체크인
6. 위기 대응 계획 작성
```

#### 🟢 낮은 위기 (LOW - Level 2)

**스트레스 높음 - 지지와 모니터링 필요**

**지표:**
- "힘들어요", "지쳐요"
- 자살 생각 없음
- 미래 계획 존재
- 지지 체계 있음
- 대처 자원 있음

**조치:**
```
1. 정기적 상담 유지
2. 지지적 관계 강화
3. 스트레스 관리 기술
4. 자기 돌봄 강화
5. 주간 모니터링
```

#### ⚪ 위기 없음 (MINIMAL - Level 1)

**안정적 - 예방적 접근**

**지표:**
- 정서 안정
- 효과적 대처
- 희망 있음
- 지지 체계 강함

**조치:**
```
1. 예방 교육
2. 웰빙 촉진
3. 정기 점검
```

## 자살 위험 평가 (Suicide Risk Assessment)

```

   □ 통제 가능성: _____

I - Intent (의도)
   □ 죽으려는 의도: □ 있음 □ 없음
   □ 강도 (0-10): _____

M - Method (수단)
   □ 특정 방법 생각: _____
   □ 접근 가능성: □ 높음 □ 중간 □ 낮음

P - Plan (계획)

T - Treatment history (치료 이력)
   □ 현재 치료: □ 받는 중 □ 중단 □ 받은 적 없음
   □ 약물 순응도: _____

   □ 절망감: ___/10
   □ 고립감: ___/10

   □ 살아야 할 이유: _____
   □ 미래 계획: _____

S - Stressors (스트레스 요인)
   □ 최근 상실: _____
   □ 재정 문제: _____
   □ 관계 문제: _____
```

### PHQ-9 Item 9 스크리닝

**질문 9**: 지난 2주간, "차라리 죽는 것이 낫겠다는 생각 또는 자해하려는 생각"을 얼마나 자주 했습니까?

```
0 = 전혀 없음
1 = 며칠 동안
2 = 7일 이상
3 = 거의 매일

점수 1 이상 → 추가 평가 필수
점수 2-3 → 즉각적 위험 평가 필수
```

### 직접 질문 가이드

**주저하지 말고 직접 물어보세요**

```
✓ "혹시 자살에 대해 생각해본 적 있나요?"
✓ "죽고 싶다는 생각이 드나요?"
✓ "자해하고 싶은 충동이 있나요?"
✓ "구체적인 계획을 세운 적 있나요?"
```

**❌ 피해야 할 질문**
```
❌ "설마 자살 생각은 안 하죠?"
❌ "괜찮아지고 있죠?"
❌ "그런 생각 하면 안 돼요"
```

**왜 직접 물어야 하나?**
- 자살에 대해 물으면 자살률이 증가한다 → **거짓**
- 오히려 안전하게 털어놓을 기회 제공
- 평가와 개입의 출발점

## 위기 개입 프로토콜

### ACT 모델 (Assess, Connect, Treat)

#### A - Assess (평가하기)

**1단계: 라포 형성**
```
"힘든 시간을 보내고 계신 것 같아요"
"여기까지 오신 것만으로도 용기 있는 일이에요"
"지금 무슨 일이 있었는지 들려주시겠어요?"
```

**2단계: 위험 평가**
- SIMPLE STEPS 사용
- 직접 질문
- 보호/위험 요인 균형

**3단계: 즉각성 판단**
- 즉각적 위험: 응급 조치
- 높은 위험: 전문가 즉시 의뢰
- 중간 위험: 안전 계획 + 빠른 추적

#### C - Connect (연결하기)

**1. 즉각적 안전 확보**
```
□ 위험 수단 제거
□ 안전한 환경 확보
□ 신뢰할 사람과 연결
□ 혼자 두지 않기
```

**2. 전문 자원 연결**
```
□ 정신건강의학과 의뢰
□ 응급실 (필요시)
□ 위기상담전화 연결
□ 지역 정신건강복지센터
```

**3. 지지 체계 활성화**
```
□ 가족/친구 (동의 하에)
□ 직장 EAP (직원지원프로그램)
□ 종교 공동체
□ 지지 그룹
```

#### T - Treat (치료하기)

**즉각적 개입**
- 안전 계획 수립
- 대처 전략 교육
- 희망 고취

**단기 개입**
- 정기 상담
- 약물 치료 (필요시)
- 위기 모니터링

**장기 개입**
- 근본 원인 치료
- 심리 치료 (CBT, DBT, ACT)
- 재발 방지

## 위기 상담 대화 기법

### DO's (해야 할 것)

```
✓ 경청하기
  "지금 정말 힘드시겠어요"
  "얼마나 고통스러우셨을지..."

✓ 공감하기
  "그 상황에서 그렇게 느끼셨을 수 있겠어요"

✓ 직접 물어보기
  "자살에 대해 생각하고 계신가요?"

✓ 판단하지 않기
  "말씀해주셔서 감사합니다"

✓ 희망 제시하기
  "지금은 그렇게 보이지 않겠지만, 도움을 받을 수 있어요"
  "함께 방법을 찾아볼 수 있습니다"

✓ 구체적 행동 계획
  "오늘 저녁까지 어떻게 안전하게 지낼까요?"

✓ 자원 연결
  "1393에 전화해보시는 건 어떨까요?"
```

### DON'Ts (하지 말아야 할 것)

```
✗ 최소화하기
  "다른 사람들은 더 힘들어요" ← NO
  "시간이 지나면 나아질 거예요" ← NO

✗ 도덕적 판단
  "자살은 이기적이에요" ← NO
  "가족 생각은 안 하세요?" ← NO

✗ 해결책 강요
  "그냥 긍정적으로 생각하세요" ← NO
  "운동하면 나아져요" ← NO

✗ 혼자 두기
  "혼자 생각할 시간 가지세요" ← NO (위기 시)

✗ 비밀 약속
  "아무한테도 안 말할게요" ← NO (생명 위험 시)

✗ 도전/시험
  "정말 죽을 거면 진작 했겠죠" ← NO

✗ 충격 주기
  "그런 말 하지 마세요!" ← NO
```

### 한국 문화 고려 사항

**체면 문화**
```
문제: "창피해서 못 말하겠어요"
대응: "도움을 요청하는 것은 용기예요"
     "많은 분들이 비슷한 어려움을 겪어요"
```

**가족 부담**
```
문제: "가족에게 짐이 되는 것 같아요"
대응: "가족들은 당신을 잃는 것이 더 큰 고통일 거예요"
     "함께 해결 방법을 찾을 수 있어요"
```

**남성 감정 표현**
```
문제: "남자가 약한 모습 보이면 안 되죠"
대응: "힘들 때 도움 구하는 것이 진짜 강함이에요"
     "감정은 누구에게나 있어요"
```

## 특정 상황별 프로토콜

### 온라인/전화 상담 중 위기 상황

**즉각적 위험 징후**
- "지금 약을 먹었어요"
- "지금 옥상에 있어요"
- "안녕히 계세요" (종결 메시지)

**프로토콜**
```
1. 침착 유지
2. 위치 파악
   "지금 어디 계세요?"
   "주소를 말씀해주실 수 있나요?"

3. 119/112 즉시 요청 (다른 라인으로)

4. 연결 유지
   "계속 저와 통화해주세요"
   "혼자 두지 않을게요"

5. 구체적 지시
   "약병을 제게 보여주세요"
   "옥상에서 내려와주세요"
   "문을 열어주세요"
```

### 자살 시도 후 생존자 지원

**즉각적 개입**
```
1. 의료적 안전 확보
2. 안정화
3. 재시도 방지 계획
```

**심리적 개입**
```
- 수치심 다루기
  "살아계셔서 다행이에요"
  "회복할 수 있어요"

- 양가감정 인정
  "복잡한 감정이 있을 수 있어요"

- 새로운 시작
  "이제부터 함께 도움을 받아요"
```

### 자살 유가족 지원 (Postvention)

**유가족의 반응**
- 죄책감: "내가 막았어야 했는데"
- 분노: "왜 나를 버렸어?"
- 수치심: "다른 사람들이 뭐라고 할까"
- 외로움: "아무도 이해 못 해"

**지원 방법**
```
✓ 비난하지 않기
✓ 충분한 애도 시간
✓ 자조 모임 연결
✓ 전문 상담 권유
✓ 장기적 지지
```

**한국 문화 고려**
```
- 사인 숨기기 경향: 이해하되, 치유를 위해 사실 직면 권장
- 빠른 회복 압박: "슬퍼할 시간이 필요해요"
- 가족 결속: 가족 단위 개입 효과적
```

## 위험 요인 및 보호 요인

### 위험 요인 (Risk Factors)

**개인적 요인**
- 정신질환 (우울, 조울증, 정신증)
- 약물 남용
- 과거 자살 시도
- 만성 통증/질병
- 충동성, 공격성
- 절망감, 무력감
- 완벽주의

**사회적 요인**
- 사회적 고립
- 최근 상실 (사별, 이별, 실직)
- 재정 문제
- 법적 문제
- 폭력 피해 (학대, 성폭력)
- 차별, 낙인

**한국 특수 요인**
- 입시/취업 실패
- 명예 손상
- 노인 빈곤/고독
- 사이버 괴롭힘
- 과로/번아웃
- 가족 불화

### 보호 요인 (Protective Factors)

**개인적 보호 요인**
- 문제 해결 능력
- 도움 요청 능력
- 자기 효능감
- 대처 기술
- 살아야 할 이유
- 미래 계획
- 종교/영적 신념

**사회적 보호 요인**
- 강한 가족 유대
- 친구 지지
- 전문가 연결
- 소속감
- 치료 순응
- 안전한 환경

**강화 방법**
```
1. 관계 강화
   "누구와 가까운가요?"
   "누구에게 연락할 수 있나요?"

2. 의미 찾기
   "살아야 할 이유는 무엇인가요?"
   "당신이 중요한 사람은 누구인가요?"

3. 미래 지향
   "내일/다음 주 계획이 있나요?"
   "기대되는 일이 있나요?"

4. 자원 연결
   "어떤 도움이 필요하세요?"
   "함께 자원을 찾아볼까요?"
```

## 자주 하는 질문 (FAQ)

**Q: 자살에 대해 직접 물어보면 자살을 유발하나요?**
A: 아닙니다. 오히려 안전하게 이야기할 기회를 제공합니다.

**Q: 안전 계약서를 쓰면 자살을 막을 수 있나요?**
A: 계약서만으로는 불충분합니다. 구체적 안전 계획과 지속적 모니터링이 필요합니다.

**Q: "관심받고 싶어서 하는 행동"인 것 같아요**
A: 모든 자살 관련 행동은 심각하게 받아들여야 합니다. "관심 끌기"도 도움 요청의 신호입니다.

**Q: 가족에게 알려야 하나요?**
A: 생명 위험이 있다면 알려야 합니다. 가능하면 본인 동의를 구하되, 위험이 크다면 동의 없이도 가능합니다.

**Q: 입원을 거부하면 어떻게 하나요?**
A: 자타해 위험이 명백하면 비자의 입원이 가능합니다. 정신건강의학과 의사 판단이 필요합니다.
