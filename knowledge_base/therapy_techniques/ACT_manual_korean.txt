# 수용전념치료(ACT) 한국어 매뉴얼

## 개요

수용전념치료(Acceptance and Commitment Therapy, ACT, "액트"로 발음)는 스티븐 헤이즈(Steven Hayes)가 개발한 심리치료 접근법으로, 심리적 고통을 없애는 것이 아니라, 고통을 수용하면서 가치 있는 삶을 살아가는 것을 목표로 합니다.

## ACT의 핵심 철학

### 심리적 유연성 (Psychological Flexibility)

**정의**
현재 순간에 완전히 접촉하고, 자신의 가치와 일치하는 방향으로 행동을 변화시키거나 지속하는 능력

```
심리적 경직 (Inflexibility)    →    심리적 유연성 (Flexibility)
회피, 투쟁                           수용, 개방
경직된 사고                         유연한 사고
과거/미래에 집착                   현재 순간 접촉
가치 상실                           가치 명확화
충동적/회피 행동                   전념 행동
```

### ACT의 기본 전제

1. **심리적 고통은 정상적이다**
   - 고통은 인간 경험의 자연스러운 부분
   - 고통을 없애려는 시도가 오히려 문제를 악화

2. **회피가 문제다**
   - "창조적 절망(Creative Hopelessness)"
   - 고통을 피하려는 노력이 효과가 없었음을 인식

3. **언어가 고통을 만든다**
   - 인간의 언어 능력이 과거를 후회하고 미래를 걱정하게 함
   - 생각과 현실을 혼동

## ACT 핵심 6가지 과정 (Hexaflex)

```
           수용 (Acceptance)
                 |
인지적 탈융합 ---|--- 현재 순간
(Defusion)       |    (Present)
                 |
           심리적 유연성
                 |
자기-맥락 -------|--- 가치
(Self-Context)   |    (Values)
                 |
           전념 행동
        (Committed Action)
```

## 1. 수용 (Acceptance)

### 정의

고통스러운 생각, 감정, 신체 감각을 있는 그대로 경험하기
- 통제하거나 없애려 하지 않기
- 회피하지 않기
- 있는 그대로 허용하기

### 수용 vs 체념

```
수용 (Acceptance)                체념 (Resignation)
능동적 선택                       수동적 포기
"느끼되, 행동은 내가 선택"        "어쩔 수 없어"
가치를 향해 나아감               멈춰 있음
개방적                           닫혀 있음
```

### 한국 문화에서의 수용

**도전**
- "참는 게 미덕" vs "건강한 수용"
- 감정 억압 문화
- "약한 모습 보이면 안 돼"

**ACT 수용**
```
억압: "슬프면 안 돼. 참아야 해" (에너지 소모, 축적)
수용: "지금 슬픔이 있구나. 슬퍼도 괜찮아" (흘러가게 함)
```

### 수용 연습

#### 1. 확장 기법 (Expansion)

**5단계 과정**
```
1. 관찰: "지금 몸 어디에 불편한 감각이 있나?"
   예: "가슴이 답답하다"

2. 호흡: 그 감각이 있는 곳으로 호흡 보내기

3. 공간 만들기: 그 감각 주위에 공간 만들기
   "조금 더 넓어질 수 있나?"

4. 허용: 그 감각이 그냥 있도록 허용
   "여기 있어도 괜찮아"

5. 함께: 이 감각과 함께 무엇을 할 수 있을까?
```

**한국어 예시**
```
상황: 발표 전 불안
"가슴이 두근거린다. 손에 땀이 난다.
이 불안이 여기 있구나. 괜찮아, 있어도 돼.
불안을 느끼면서도 발표장에 들어갈 수 있어."
```

#### 2. 의지 연습 (Willingness)

**의지 vs 욕구**
```
욕구 (Wanting): "불안이 사라지면 좋겠어"
의지 (Willing): "불안이 있어도 중요한 일을 할 의향이 있어"
```

**질문**
- "이 감정/생각과 함께 있을 의향이 있나?"
- "가치를 위해 이 불편함을 기꺼이 경험할 수 있나?"

## 2. 인지적 탈융합 (Cognitive Defusion)

### 정의

생각과 거리 두기
- 생각을 사실이 아닌 "단지 생각"으로 보기
- 생각에 휘둘리지 않기
- 생각을 관찰하기

### 융합 vs 탈융합

```
융합 (Fusion)                    탈융합 (Defusion)
"나는 실패자야"                   "나는 '나는 실패자야'라는 생각을 하고 있어"
생각 = 사실                       생각 = 정신적 사건
생각에 사로잡힘                  생각을 관찰함
생각이 나를 통제                 내가 생각을 알아차림
```

### 한국 문화와 융합

**흔한 융합된 생각**
```
"다른 사람들이 나를 이렇게 볼 거야" (마음 읽기)
"나는 부모님을 실망시켰어" (자기 판단)
"1등 아니면 실패야" (흑백 논리)
"나는 착한 자녀여야 해" (당위적 사고)
```

### 탈융합 기법

#### 1. "생각하고 있다" 덧붙이기

```
융합: "나는 쓸모없어"
탈융합: "나는 지금 '나는 쓸모없어'라는 생각을 하고 있어"
```

#### 2. "고맙습니다, 마음아" 기법

```
불안한 생각: "실패할 거야"
반응: "염려해줘서 고마워, 마음아. 하지만 난 계속 갈 거야"
```

#### 3. 생각에 이름 붙이기

```
"아, '비교하기' 생각이 또 왔네"
"아, '완벽주의자' 생각이구나"
"'재판관' 생각이 등장했네"
```

#### 4. 생각을 잎사귀에 태우기

```
시냇물에 나뭇잎이 떠내려가는 상상
각 잎사귀에 생각을 올려놓고 보내기
"흘러가도록 둔다"
```

#### 5. 노래로 부르기

부정적 생각을 생일 축하 노래 멜로디로 부르기
→ 생각의 힘이 약해짐

#### 6. 다른 목소리로 말하기

생각을 만화 캐릭터 목소리로 말하기
→ 진지함이 줄어듦

### 한국어 탈융합 연습

```
생각: "나는 사회생활을 못 해"
1단계: 알아차리기 "이 생각이 있구나"
2단계: 이름 붙이기 "자기비판 생각이네"
3단계: 감사하기 "보호하려는 거구나, 고마워"
4단계: 선택하기 "이 생각을 가지고도 나갈 수 있어"
```

## 3. 현재 순간과의 접촉 (Being Present)

### 정의

지금 이 순간에 유연하게 주의를 기울이기
- 과거의 후회나 미래의 걱정이 아닌
- 바로 지금, 여기

### 시간 여행의 문제

```
과거        현재        미래
후회         |         걱정
반추         ↓         예상
자책       여기!       불안
```

**한국 문화의 시간 여행**
- 과거: "그때 다른 대학 갔으면...", "그때 다르게 했어야..."
- 미래: "노후는 어떡하지?", "취직 못 하면?", "결혼은?"

### 현재 순간 연습

#### 1. 5-4-3-2-1 그라운딩 기법

```
5 - 보이는 것 5가지 (책상, 창문, 컵...)
4 - 만져지는 것 4가지 (의자, 옷감, 바닥...)
3 - 들리는 것 3가지 (시계 소리, 차 소리...)
2 - 냄새 나는 것 2가지 (커피, 공기...)
1 - 맛 느껴지는 것 1가지 (입안의 맛)
```

#### 2. 마음챙김 관찰

**일상 활동 마음챙김**
- 걷기: 발바닥 감각, 체중 이동
- 먹기: 맛, 질감, 온도, 씹는 소리
- 설거지: 물의 온도, 거품, 접시의 감촉

**한국 문화 활용**
- 차 마시기: 찻잔 온기, 향, 맛
- 산책: 계절의 변화 느끼기
- 식사: 음식 하나하나 음미

#### 3. 호흡 닻 내리기

호흡을 닻으로 사용
- 생각에 휩쓸릴 때
- 호흡으로 돌아오기
- 지금 이 순간 재접촉

## 4. 맥락으로서의 자기 (Self as Context)

### 세 가지 자기

```
1. 개념화된 자기 (Self as Content)
   "나는 실패자야", "나는 내성적이야"
   → 경직되고 제한적

2. 과정으로서의 자기 (Self as Process)
   생각, 감정, 감각을 알아차리는 자기
   "나는 지금 불안을 느끼고 있어"

3. 맥락으로서의 자기 (Self as Context)
   모든 경험을 담는 의식 그 자체
   "관찰하는 나", "체스판"
```

### 체스판 은유

```
       자기 = 체스판

[흰색 말]      [검은색 말]
긍정적 경험    부정적 경험
기쁨, 사랑     슬픔, 불안

문제: 우리는 흰색 말이 이기길 원함 (회피)
진실: 체스판은 어떤 말이 이겨도 괜찮음
      모든 경험을 담을 수 있음
```

**한국어로**
```
"나는 이 모든 경험을 담을 수 있는 공간이야
불안도, 기쁨도, 슬픔도, 모두 여기 있을 수 있어"
```

### 관찰자 자기 연습

```
"나는 내 생각을 관찰하고 있다"
"나는 내 감정을 느끼고 있다"
"나는 내 기억을 기억하고 있다"

→ 생각하는 나 vs 관찰하는 나
→ 관찰하는 나는 항상 안전하다
```

## 5. 가치 (Values)

### 정의

우리가 원하는 삶의 방향
- 목표가 아닌 방향
- 도착점이 아닌 여정
- 선택한 삶의 질

### 가치 vs 목표

```
가치 (Values)                     목표 (Goals)
방향 (서쪽으로 가기)               목적지 (부산 도착)
과정                              결과
계속되는 것                       달성되는 것
"사랑하는 사람 되기"              "결혼하기"
"건강하게 살기"                   "5kg 감량"
```

### 한국 문화와 가치

**타인의 기대 vs 내 가치**

```
부모님 기대: 의사, 변호사
사회 기대: 결혼, 출산, 집 마련
또래 기대: 대기업, 승진

나의 진짜 가치: "________________"
```

**질문**
- "만약 아무도 판단하지 않는다면, 나는 무엇을 하고 싶은가?"
- "죽기 전에 뒤돌아봤을 때, 어떤 삶을 살았기를 바라는가?"
- "내 묘비명에 뭐라고 쓰이길 원하는가?"

### 가치 영역

**1. 관계 (Relationships)**
- 가족: 어떤 딸/아들/형제/부모가 되고 싶은가?
- 친구: 어떤 친구가 되고 싶은가?
- 연인: 어떤 파트너가 되고 싶은가?

**2. 일/학업 (Work/Education)**
- 어떤 직원/학생이 되고 싶은가?
- 일을 통해 무엇을 표현하고 싶은가?

**3. 자기 돌봄 (Self-care)**
- 몸: 건강, 운동
- 마음: 정서적 웰빙
- 영혼: 영적 성장

**4. 여가 (Leisure)**
- 즐거움, 휴식, 놀이
- 취미, 관심사

**5. 시민성 (Citizenship)**
- 사회 기여
- 환경
- 공동체

### 가치 명료화 연습

#### 1. 80세 생일 연습

```
"80세 생일 파티에서
사랑하는 사람들이 나에 대해
무엇을 말해주길 바라는가?"

가족: "______________________"
친구: "______________________"
동료: "______________________"
```

#### 2. 가치 카드 분류

중요도에 따라 가치를 분류:
- 매우 중요
- 중요
- 덜 중요

**한국 문화 맥락 가치 예시**
- 가족 유대 (家族)
- 성실함 (誠實)
- 겸손 (謙遜)
- 배움 (學習)
- 정직 (正直)
- 용기 (勇氣)
- 연민 (慈悲)
- 창의성 (創意)
- 자유 (自由)
- 조화 (和)

#### 3. 방향 설정

```
가치: 건강
현재 위치: 3/10
장애물: 야근, 운동 시간 없음, 편의점 식사
작은 행동: 계단 이용, 물 1L 마시기, 주 1회 집밥
```

## 6. 전념 행동 (Committed Action)

### 정의

가치와 일치하는 구체적 행동을 지속적으로 실천하기
- 말이 아닌 행동
- 작게 시작하기
- 지속하기

### 전념 행동의 특징

```
1. 가치 기반: "왜?"가 명확
2. 구체적: 언제, 어디서, 무엇을
3. 달성 가능: 현실적
4. 유연함: 실패해도 다시 시작
```

### SMART 행동 목표

```
S - Specific (구체적): "운동하기" → "월수금 아침 7시 동네 걷기 30분"
M - Measurable (측정 가능): 횟수, 시간으로 측정
A - Achievable (달성 가능): 너무 크지 않게
R - Relevant (가치 관련): 내 가치와 연결
T - Time-bound (시간 제한): 언제까지
```

**한국 직장인 예시**
```
가치: 가족과의 유대
행동: 매주 일요일 저녁 6시, 부모님께 전화 30분
      월 1회 셋째 주 토요일, 가족 식사
```

### 장애물 다루기

#### 1. 장애물 예상하기

```
행동: 주 3회 운동
장애물:
- 내적: "피곤해", "내일 하지 뭐", "의미 없어"
- 외적: 야근, 날씨, 약속

대처:
- 내적: 탈융합 "피곤하다는 생각이네. 그래도 갈 수 있어"
- 외적: Plan B (집에서 운동, 짧게라도)
```

#### 2. 작게 시작하기

```
❌ "매일 1시간 운동"
✓ "주 1회 10분 걷기" → 성공 경험 → 점진적 증가
```

#### 3. 실패 후 재시작

```
완벽주의: "3일 못 했으니 실패야. 그만둬야지"
ACT: "3일 못 했네. 오늘 다시 시작하면 돼"
```

### 행동 활성화 계획표

| 날짜 | 가치 | 구체적 행동 | 실행 여부 | 장애물 | 대처 |
|------|------|-------------|-----------|--------|------|
| 월 | 건강 | 아침 걷기 30분 | ✓ | 늦잠 | 전날 일찍 잠 |
| 화 | 관계 | 친구에게 연락 | ✓ | - | - |
| 수 | 학습 | 책 읽기 20분 | ✗ | 야근 | 주말에 보충 |

## ACT 주요 은유와 연습

### 1. 승객이 가득한 버스 (Passengers on the Bus)

```
당신은 버스 기사
승객들 = 부정적 생각/감정
"너는 못 해", "실패할 거야", "무서워"

승객들과 싸우면?
→ 버스가 멈춤, 목적지에 못 감

승객들을 그냥 태우고 운전하면?
→ 떠들어도, 목적지로 계속 감
```

**한국어 버전**
```
승객: "다른 사람들이 뭐라고 할까?"
기사: "태워둘게. 하지만 운전은 내가 해"
→ 가치(목적지)를 향해 계속 운전
```

### 2. 숨 참기 은유 (Holding Your Breath)

```
"불안을 없애려는 것은 숨을 계속 참는 것과 같다"

처음: 괜찮음
시간 지나면: 고통스러움
포기하고 숨 쉬면: 원래대로

→ 회피는 단기적 안도, 장기적 고통
```

### 3. 구덩이에서 삽질하기 (Digging the Hole)

```
구덩이 = 문제/고통
삽 = 해결 노력

열심히 파면?
→ 구덩이만 깊어짐

해결책: 삽을 내려놓고 멈추기
→ 수용
```

### 4. 줄다리기 괴물 (Tug of War with a Monster)

```
당신 ⟷ (구덩이) ⟷ 괴물(불안)

계속 당기면?
→ 지치고 구덩이로 빠질 위험

해결책: 줄을 놓기 (수용)
→ 싸움 끝남
```

### 5. 두 개의 산 (Two Mountains)

```
고통의 산              가치의 산
(회피, 단기 안도)      (의미, 장기 만족)

고통의 산: 쉬움, 하지만 황량함
가치의 산: 힘듦, 하지만 아름다운 경치

어느 산에 오를 것인가?
```

## ACT 실전 적용

### 예시 1: 사회 불안

**상황**: 회식 참석이 불안함

```
1. 알아차리기 (Present)
   "가슴이 두근거리고, '창피당할 거야'라는 생각"

2. 탈융합 (Defusion)
   "'창피당할 거야'라는 생각을 하고 있구나"

3. 수용 (Acceptance)
   "불안이 있어도 괜찮아. 느끼고 가자"

4. 가치 (Values)
   "동료와의 관계가 중요해"

5. 전념 행동 (Committed Action)
   "30분만 참석하고 나올 수 있어"
```

### 예시 2: 직장에서 상사에게 의견 말하기

**상황**: 의견을 말하고 싶지만 두려움

```
융합된 생각: "내가 말하면 무시당할 거야"
탈융합: "내가 '무시당할 거야'라는 생각을 하고 있구나"

회피: 아무 말 안 함 (단기 안도, 장기 후회)
수용: "두려움을 느끼면서도 말할 수 있어"

가치: 정직함, 자기 존중, 기여
행동: "제 생각에는..."이라고 말하기
```

### 예시 3: 부모님의 결혼 압박

**상황**: 명절마다 결혼 이야기

```
자동 반응: 짜증, 회피, 거짓말
불안: "평생 혼자면 어떡하지"

ACT 접근:
1. 수용: "부모님의 걱정, 내 불안, 둘 다 있어도 괜찮아"
2. 탈융합: "'혼자는 불행하다'는 생각일 뿐"
3. 가치: 나에게 관계가 중요한가? 어떤 파트너십을 원하나?
4. 행동: 솔직하고 존중하는 대화
   "마음은 감사하지만, 제 속도로 가겠습니다"
```

## 한국 문화 맥락에서의 ACT

### 1. 체면 문화

**융합**: "창피하면 안 돼" "다른 사람이 뭐라고 할까"

**ACT 접근**
```
- 탈융합: "체면에 대한 생각이구나"
- 가치: "타인의 평가 vs 나의 진정성"
- 선택: "조금 불편해도, 진실하게 살고 싶어"
```

### 2. 효(孝) 문화

**융합**: "부모님 뜻을 따라야 해" "반대하면 불효야"

**ACT 접근**
```
- 수용: "부모님을 사랑하면서도 내 길을 갈 수 있어"
- 가치: "효도 AND 자기 결정"
- 행동: 존중하며 내 선택 표현
```

### 3. 집단주의

**융합**: "나만 생각하면 이기적이야"

**ACT 접근**
```
- 가치: "타인 배려 AND 자기 돌봄"
- 유연성: "때로는 나를, 때로는 타인을"
- 균형: 건강한 경계
```

### 4. 성취 압박

**융합**: "성공하지 못하면 실패자야" "1등 아니면 의미 없어"

**ACT 접근**
```
- 가치: "성공이 내게 무엇을 의미하나?"
- 재정의: "내 기준의 성공"
- 과정: 결과보다 가치 있는 과정
```

## 심리적 유연성 척도

자가 평가 (0=전혀, 10=매우):

```
수용:
□ 불편한 감정을 느낄 수 있다 ___/10

탈융합:
□ 부정적 생각에 휘둘리지 않는다 ___/10

현재:
□ 지금 이 순간에 집중할 수 있다 ___/10

자기:
□ 나를 생각/감정과 분리해 볼 수 있다 ___/10

가치:
□ 내게 중요한 것이 무엇인지 안다 ___/10

전념:
□ 가치에 맞게 행동한다 ___/10

총점: ___/60
```

## ACT와 마음챙김 명상

### 1. 생각 관찰 명상 (10분)

```
1. 편안하게 앉기
2. 호흡에 주의
3. 생각이 떠오르면 알아차리기
   "생각이 있구나"
4. 판단 없이 관찰
5. 생각이 구름처럼 지나가게 두기
6. 다시 호흡으로
```

### 2. 잎사귀 명상 (5분)

```
1. 시냇물 상상
2. 나뭇잎들이 떠내려감
3. 각 생각을 잎사귀에 올려놓기
4. 흘러가는 것을 지켜보기
5. 붙잡지 않기
```

### 3. 하늘과 날씨 명상 (5분)

```
나 = 하늘 (항상 있음, 광대함)
생각/감정 = 날씨 (변함, 지나감)

"나는 하늘이고,
생각과 감정은 날씨일 뿐
날씨가 어떻든, 하늘은 괜찮다"
```

## ACT의 한계와 주의사항

### 적합한 경우

- 만성 통증
- 불안, 우울
- 약물 중독
- 스트레스 관리
- 가치 명확화 필요

### 주의 사항

- 수용은 체념이 아님
- 가치는 강요될 수 없음
- 즉각적 변화 기대하지 않기
- 심각한 위기 상황에서는 안전 우선

## 자기 연민 (Self-Compassion)

ACT는 자기 연민과 잘 결합됨:

```
1. 마음챙김 (Mindfulness)
   고통을 알아차리기

2. 공통된 인간성 (Common Humanity)
   "나만 힘든 게 아니야"

3. 자기 친절 (Self-Kindness)
   자신에게 친절하게
```

**한국어 자기 연민 문구**
```
"지금 힘드네. 괜찮아"
"이럴 수 있어. 나도 인간이니까"
"나를 비난하는 대신, 위로해줄게"
"완벽하지 않아도 돼"
```

- 매일 연습
