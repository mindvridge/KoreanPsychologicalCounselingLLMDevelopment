# 변증법적 행동치료(DBT) 한국어 매뉴얼

## 개요

변증법적 행동치료(Dialectical Behavior Therapy, DBT)는 마샤 리네한(Marsha Linehan) 박사가 개발한 인지행동치료의 한 형태로, 감정 조절의 어려움을 겪는 사람들, 특히 경계선 성격장애, 자해 행동, 자살 위험이 있는 사람들을 위해 설계되었습니다.

## DBT의 핵심 철학

### 1. 변증법적 사고 (Dialectical Thinking)

**변증법의 의미**
- 대립되는 두 가지가 동시에 참일 수 있다는 관점
- "그리고(AND)" 사고: "나는 지금 괜찮다 그리고 변화가 필요하다"
- "아니면(OR)" 사고에서 벗어나기

**핵심 변증법**
```
수용 (Acceptance)  ⟷  변화 (Change)
있는 그대로         필요한 변화
자기 수용           성장 추구
```

**한국 문화에서의 변증법**
- "효도해야 한다" AND "나의 삶도 중요하다"
- "가족을 위해 희생" AND "자기 돌봄도 필요"
- "겸손해야 한다" AND "내 가치를 인정할 수 있다"

### 2. 마음챙김 (Mindfulness)

DBT의 모든 기술의 토대가 되는 핵심 기술입니다.

## DBT 4대 기술 모듈

## 모듈 1: 마음챙김 기술 (Mindfulness Skills)

### 핵심 마음챙김 기술

#### "무엇(What)" 기술 - 무엇을 할 것인가

**1. 관찰하기 (Observe)**
- 판단 없이 경험을 알아차리기
- 생각, 감정, 신체 감각을 그저 주목하기

**예시**
```
판단적: "내가 왜 이렇게 불안한 거지? 이상한 것 같아"
관찰적: "지금 가슴이 두근거리고, 손에 땀이 난다. 불안이라는 감정이 있구나"
```

**한국어 연습**
- "화가 나네" (알아차림)
- "슬픔이 가슴에 있구나" (관찰)
- "머리가 복잡하다" (인식)

**2. 기술하기 (Describe)**
- 관찰한 것을 말이나 글로 표현하기
- 사실만 기술하고 해석은 배제

**예시**
```
해석: "상사가 나를 싫어하나 봐"
기술: "상사가 회의에서 내 의견에 대답하지 않았다"
```

**3. 참여하기 (Participate)**
- 지금 이 순간의 활동에 완전히 몰입하기
- 자의식 내려놓기

**한국 문화 적용**
- 식사할 때 음식에 집중 (스마트폰 내려놓기)
- 차 마실 때 다도의 자세로
- 산책할 때 자연에 온전히 머물기

#### "어떻게(How)" 기술 - 어떻게 할 것인가

**1. 비판단적으로 (Non-judgmentally)**
- "좋다/나쁘다" 판단 없이
- 사실을 있는 그대로 보기

**한국 문화에서의 도전**
- 체면 문화: "창피해" → "얼굴이 뜨겁다"
- 비교 문화: "나만 못하네" → "다른 결과가 나왔구나"
- 완벽주의: "실패했어" → "원하는 결과가 아니었구나"

**2. 한 가지에 집중하여 (One-mindfully)**
- 한 번에 한 가지만
- 멀티태스킹 피하기

**예시**
```
❌ 밥 먹으면서 TV 보면서 폰 보기
✓ 식사에만 집중하기
```

**3. 효과적으로 (Effectively)**
- 무엇이 옳은지보다 무엇이 효과적인지
- 상황에 맞는 행동 선택

**한국 문화 적용**
- "이게 맞아?"보다 "이게 지금 도움이 될까?"
- 체면보다 실질적 문제 해결

### 마음챙김 연습법

**1. 호흡 마음챙김 (5분)**
```
1. 편안한 자세로 앉기
2. 눈을 감거나 부드럽게 뜨기
3. 코로 들어오고 나가는 호흡 관찰
4. 생각이 떠오르면 알아차리고 다시 호흡으로
5. 판단 없이, 부드럽게
```

**2. 바디스캔 (10분)**
- 발끝부터 머리까지 신체 감각 관찰
- 긴장, 이완, 통증, 온도 등 알아차리기

**3. 일상 마음챙김**
- 양치질 마음챙김: 칫솔의 움직임, 치약 맛
- 걷기 마음챙김: 발바닥 감각, 체중 이동
- 설거지 마음챙김: 물의 온도, 거품 감촉

## 모듈 2: 고통 감내 기술 (Distress Tolerance Skills)

위기 상황에서 견디고 살아남기 위한 기술입니다.

### 위기 생존 기술

#### STOP 기술

```
S - Stop (멈추기): 충동적으로 행동하지 말고 멈추기
T - Take a step back (한 걸음 물러서기): 상황에서 심리적으로 물러나기
O - Observe (관찰하기): 무슨 일이 일어나는지 알아차리기
P - Proceed mindfully (마음챙김하며 진행하기): 효과적으로 행동하기
```

**한국 상황 예시**
```
상황: 상사가 회의에서 당신을 비판했을 때
S - 즉각 반응하지 않고 멈춤
T - "잠깐, 감정적으로 대응하면 후회할 수 있어"
O - "지금 화가 나고, 얼굴이 뜨겁고, 말하고 싶은 충동이 있구나"
P - "지금은 참고, 나중에 1:1로 대화를 요청하자"
```

#### TIP 기술 - 즉각적 생리 변화

**T - Temperature (온도)**
- 찬물로 얼굴 씻기
- 얼음 쥐기
- 차가운 샤워

**I - Intense exercise (격렬한 운동)**
- 제자리 뛰기
- 계단 오르기
- 빠르게 걷기

**P - Paced breathing (조절된 호흡)**
```
4초 들이마시기
7초 참기
8초 내쉬기
```

**P - Paired muscle relaxation (짝을 이룬 근육 이완)**
- 긴장시키고 이완하기 반복

### 현실 수용 기술

#### 급진적 수용 (Radical Acceptance)

**정의**
- 변화시킬 수 없는 현실을 완전히 받아들이기
- 저항을 멈추고 있는 그대로 인정하기

**한국 문화에서의 적용**
```
상황: 명문대에 떨어졌다
저항: "이건 말도 안 돼. 내 인생 끝났어"
수용: "떨어진 것은 사실이다. 고통스럽지만, 이것이 현실이다.
      다른 길을 찾을 수 있다"
```

**급진적 수용 연습**
1. 현실을 있는 그대로 말하기
2. "이것이 현실이다" 반복하기
3. 저항하는 생각 알아차리기
4. 수용이 포기나 동의가 아님을 기억하기

#### 전환 (Turning the Mind)

현실을 받아들이기로 **선택**하는 것
- 거부에서 수용으로 의식적으로 전환
- 한 번이 아니라 반복적으로

#### 의지 (Willingness) vs 고집 (Willfulness)

```
의지 (Willingness)           고집 (Willfulness)
"어떻게 하면 될까?"          "절대 안 돼!"
유연함                       경직됨
협력적                       대립적
효과적                       비효과적
```

**한국 문화 예시**
```
고집: "내가 왜 먼저 사과해야 해? 저 사람이 잘못했는데!"
의지: "먼저 사과하면 관계가 회복될 수 있어. 내 평화를 위해 선택할 수 있어"
```

### ACCEPTS 기술 - 주의 분산

위기 상황에서 잠시 주의를 돌리는 기술:

```
A - Activities (활동): 청소, 운동, 게임
C - Contributing (기여): 다른 사람 돕기, 봉사
C - Comparisons (비교): 더 나쁜 상황, 과거의 나
E - Emotions (감정): 반대 감정 유발 (슬플 때 코미디)
P - Pushing away (밀어내기): 생각을 상자에 넣기
T - Thoughts (생각): 숫자 세기, 퍼즐
S - Sensations (감각): 강한 맛, 향기, 소리
```

**한국 상황 활용**
- A: K-드라마 보기, 요리하기
- C: 부모님께 전화, 친구 위로
- E: 트로트 들으며 기분 전환
- T: 구구단 외우기, 노래 가사 떠올리기

### IMPROVE 기술 - 순간 개선

```
I - Imagery (심상): 평화로운 장면 떠올리기 (제주 바다, 한라산)
M - Meaning (의미): 고통에서 의미 찾기
P - Prayer (기도): 명상, 기도, 영적 연결
R - Relaxation (이완): 근육 이완, 마사지
O - One thing (한 가지): 지금 이 순간만 집중
V - Vacation (휴가): 짧은 휴식, 심리적 휴가
E - Encouragement (격려): 자기 격려 "할 수 있어", "잘하고 있어"
```

## 모듈 3: 감정 조절 기술 (Emotion Regulation Skills)

### 감정 이해하기

#### 감정의 기능

**1. 의사소통**
- 다른 사람에게 신호 보내기
- 예: 화는 경계 침해를 알림

**2. 행동 동기화**
- 행동을 빠르게 조직화
- 예: 두려움은 도망치게 함

**3. 자기 검증**
- 내 경험이 유효함을 확인

### 감정 조절 모델

```
사건 → 해석 → 신체 변화 → 감정 → 행동 충동
```

**예시**
```
사건: 친구가 약속에 늦음
해석: "나를 무시하나?"
신체: 가슴 답답, 얼굴 화끈
감정: 화남 (70%)
충동: 소리 지르고 싶음
```

### 감정 조절 기술

#### 1. 반대 행동 (Opposite Action)

감정의 충동과 **반대로** 행동하기

**화날 때**
- 충동: 소리 지르기, 비난하기
- 반대 행동: 부드럽게 말하기, 잠시 물러나기

**불안할 때**
- 충동: 회피하기, 도망가기
- 반대 행동: 접근하기, 마주하기

**슬플 때 (우울)**
- 충동: 침대에 누워있기
- 반대 행동: 활동하기, 운동하기

**한국 문화 예시**
```
상황: 회식 자리가 불안해서 빠지고 싶음
반대 행동: 참석하되, 30분만 있고 먼저 나오기
결과: "생각보다 괜찮았네. 다음엔 더 오래 있을 수 있을 것 같아"
```

#### 2. 문제 해결

감정이 정당한 이유가 있을 때

**단계**
1. 문제 정의: 무엇이 문제인가?
2. 브레인스토밍: 가능한 해결책 모두 나열
3. 평가: 각 해결책의 장단점
4. 선택: 최선의 해결책 선택
5. 실행: 계획대로 실행
6. 평가: 효과 확인

#### 3. ABC PLEASE 기술

**ABC - 긍정 경험 축적**
```
A - Accumulate positive emotions (긍정 감정 축적)
   - 단기: 즐거운 활동 (산책, 음악, 맛있는 음식)
   - 장기: 가치 추구 (학업, 경력, 관계)

B - Build mastery (숙달감 구축)
   - 성취감을 주는 활동
   - 예: 새로운 기술 배우기, 요리, 운동

C - Cope ahead (미리 대처하기)
   - 어려운 상황 예상
   - 대처 전략 리허설
```

**PLEASE - 신체 돌보기**
```
PL - Treat Physical iLlness (신체 질병 치료)
E  - Balance Eating (균형 잡힌 식사)
A  - Avoid mood-altering substances (기분 변화 물질 피하기)
S  - Balance Sleep (수면 균형)
E  - Get Exercise (운동하기)
```

**한국인 맞춤 PLEASE**
- E: 규칙적인 식사 (아침 거르지 않기)
- A: 과도한 카페인, 음주 줄이기
- S: 밤샘 문화 벗어나기, 11시 취침
- E: 등산, 배드민턴, 걷기 등

### 취약성 줄이기

**취약성 요인**
- 수면 부족
- 불규칙한 식사
- 신체 질병
- 스트레스 누적

**보호 요인 강화**
- 규칙적인 생활
- 사회적 지지
- 자기 돌봄
- 긍정 활동

## 모듈 4: 대인관계 효율성 기술 (Interpersonal Effectiveness Skills)

### 목표 설정

대인관계에서 세 가지 목표의 균형:

```
1. 목적 목표 (Objective): 원하는 것 얻기
2. 관계 목표 (Relationship): 관계 유지/개선
3. 자존감 목표 (Self-respect): 자존감 지키기
```

**한국 문화에서의 도전**
- 관계 목표를 과도하게 우선시
- 자기 욕구 표현을 이기적으로 봄
- "눈치" 때문에 직접적 요청 어려움

### DEAR MAN 기술 - 원하는 것 얻기

목적 목표 달성을 위한 기술

```
D - Describe (기술하기)
   사실을 객관적으로 기술
   "어제 약속 시간에 30분 늦으셨어요"

E - Express (표현하기)
   감정이나 의견 표현
   "제가 좀 속상했어요"

A - Assert (주장하기)
   원하는 것 명확히 말하기
   "다음부터는 늦으면 미리 연락 주시면 좋겠어요"

R - Reinforce (강화하기)
   긍정적 결과 제시
   "그러면 제가 안심하고 기다릴 수 있을 것 같아요"

---

M - Mindful (마음챙김)
   목표에 집중, 산만해지지 않기
   "그건 다른 문제고, 지금은 약속 시간 얘기예요"

A - Appear confident (자신감 있게)
   목소리, 자세, 눈맞춤

N - Negotiate (협상하기)
   타협점 찾기
   "10분까지는 괜찮아요. 그 이상이면 연락 주세요"
```

**한국 문화 적용 예시**
```
상황: 부모님이 자주 결혼 압박

D: "어머니, 요즘 만날 때마다 결혼 이야기를 하시는 것 같아요"
E: "저도 부모님 마음은 이해하지만, 압박감을 느껴요"
A: "결혼 이야기는 제가 준비됐을 때 먼저 꺼내겠습니다"
R: "그러면 저희 만남이 더 편안할 것 같아요"

M: (다른 주제로 넘어가려 할 때) "그건 나중에 얘기하고, 이 부분만 이해해주세요"
A: 눈 맞추고, 침착하게
N: "1년에 한두 번 정도는 괜찮아요"
```

### GIVE 기술 - 관계 유지/개선

관계 목표 달성을 위한 기술

```
G - Gentle (부드럽게)
   공격, 비난, 협박 피하기
   ❌ "당신은 항상 그러네요!"
   ✓ "이번에 이런 일이 있었어요"

I - Interested (관심 보이기)
   상대방 말 경청
   고개 끄덕이기, 요약하기

V - Validate (타당화하기)
   상대방 감정/생각 인정
   "그렇게 느낄 수 있겠네요"
   "그 상황에서는 힘들었겠어요"

E - Easy manner (편안한 태도)
   유머, 미소
   가볍게, 공손하게
```

**한국 문화 활용**
```
G: 높임말 사용, 완곡하게 표현
   "혹시 가능하시다면..."
   "괜찮으시면..."

I: 적극적 경청
   "네, 네" 추임새
   "그래서요?" 관심 표시

V: 공감 표현
   "고생 많으셨겠어요"
   "마음 많이 힘드셨겠네요"

E: 차나 식사 제안
   "이따가 차 한잔 하실래요?"
```

### FAST 기술 - 자존감 지키기

자존감 목표 달성을 위한 기술

```
F - Fair (공정하게)
   자신과 타인 모두에게 공정
   내 욕구도 상대 욕구만큼 중요

A - Apologies (사과 자제)
   불필요한 사과 하지 않기
   ❌ "죄송하지만, 제 의견은..."
   ✓ "제 생각은..."

S - Stick to values (가치 고수)
   내 가치관 지키기
   타인의 압박에 굴복하지 않기

T - Truthful (진실하게)
   거짓말하거나 과장하지 않기
   솔직하게, 진실하게
```

**한국 문화 도전과 적용**
```
F: 겸손과 공정함의 균형
   "나도 중요하다"

A: 습관적 "죄송합니다" 줄이기
   반사적 사과 → 의식적 선택
   꼭 필요할 때만 사과

S: "다른 사람들이 뭐라고 하든" 내 가치 지키기
   체면보다 진정성

T: "괜찮아요" 습관 대신
   진짜 감정 표현하기
```

### 관계 우선순위 정하기

상황에 따라 어떤 목표를 우선할지 결정:

**목적 우선 (DEAR MAN)**
- 중요한 요청
- 관계가 튼튼할 때
- 자신의 권리가 명확할 때

**관계 우선 (GIVE)**
- 관계가 더 중요할 때
- 상대가 힘들 때
- 장기적 관계 고려

**자존감 우선 (FAST)**
- 가치가 위협받을 때
- 자신을 존중받아야 할 때
- 경계가 침해될 때

## 한국 문화 맥락에서의 DBT

### 1. 집단주의 vs 개인의 욕구

**변증법적 통합**
```
"가족/집단을 배려한다" AND "나의 욕구도 존중한다"
```

**실천 방법**
- 무조건 희생 ❌
- 건강한 경계 설정 ✓
- 서로의 욕구 협상 ✓

### 2. 감정 표현의 어려움

**한국 문화**
- "참는 게 미덕"
- "감정 표현은 약함"
- 특히 남성의 감정 표현 억제

**DBT 접근**
- 감정 타당화: "이 감정은 자연스럽다"
- 건강한 표현 방법 배우기
- 억압이 아닌 조절

### 3. 체면 문화

**도전**
- 실패를 창피하게 여김
- 도움 요청 꺼림
- 취약함 보이기 두려움

**DBT 재구성**
- 도움 요청은 용기
- 취약함은 인간적
- 완벽하지 않아도 괜찮음

### 4. 높은 기대와 압박

**문화적 압박**
- 학업/직장 성공 압박
- 결혼/출산 압박
- 부모 기대

**DBT 기술 적용**
- 급진적 수용: "압박이 있다는 것을 인정"
- 가치 명확화: "내가 진짜 원하는 것은?"
- 효과적으로 행동: "지금 무엇이 도움이 될까?"

## DBT 그룹 및 개인 치료

### 표준 DBT 구조

**1. 개인 치료 (주 1회, 60분)**
- 일지 검토
- 위기 개입
- 기술 코칭
- 치료 방해 행동 다루기

**2. 그룹 기술 훈련 (주 1회, 2시간)**
- 4개 모듈 교육
- 과제 검토
- 연습

**3. 전화 코칭 (필요시)**
- 실시간 기술 적용 도움

**4. 치료자 자문팀**
- 치료자 지원

### 한국에서의 DBT 적용

**그룹 특성**
- 위계적 그룹 역동 고려
- 자기 개방 어려움 인식
- 신뢰 구축에 더 많은 시간

**가족 참여**
- 가족 교육 세션
- 가족의 이해와 지지 중요
- 가족 단위 문제 해결

## 치료 목표 위계

DBT는 명확한 목표 우선순위가 있습니다:

```
1순위: 생명 위협 행동 (자살, 자해)
       ↓
2순위: 치료 방해 행동 (결석, 늦참)
       ↓
3순위: 삶의 질 저해 행동 (고립, 실직)
       ↓
4순위: 기술 습득 및 강화
```

## 자기 위안 (Self-Soothing)

다섯 가지 감각을 사용한 자기 위안:

**시각**
- 아름다운 풍경 보기 (한강, 산, 공원)
- 좋아하는 사진, 미술 작품
- 꽃, 자연

**청각**
- 좋아하는 음악 (클래식, K-pop, 재즈)
- 자연 소리 (빗소리, 파도 소리)
- ASMR

**후각**
- 향초, 아로마
- 커피 향기
- 계절 냄새

**미각**
- 좋아하는 차 (녹차, 허브티)
- 천천히 음미하며 먹기
- 한 입 한 입 음미

**촉각**
- 따뜻한 목욕
- 부드러운 담요
- 애완동물 쓰다듬기
- 마사지

## 가치와 삶의 의미

### 가치 명확화

"내게 진짜 중요한 것은 무엇인가?"

**영역별 가치**
- 가족/관계
- 직업/학업
- 건강/웰빙
- 영적/도덕적
- 취미/즐거움
- 사회적 기여

**한국 문화 맥락**
```
타인의 기대: "명문대, 대기업, 결혼"
내 진짜 가치: "___________________"
```

### 가치 기반 삶 살기

**가치 vs 목표**
- 가치: 방향 (북쪽을 향해 가기)
- 목표: 도달점 (서울 도착)

**가치 행동 연습**
```
가치: 가족과의 유대
행동: 주 1회 부모님께 전화
      월 1회 함께 식사

가치: 건강
행동: 주 3회 운동 30분
      매일 충분한 수면
```

### 위기 상황 체크리스트

```
□ STOP 사용했나?
□ TIP 기술 시도했나?
□ 안전한 사람에게 연락했나?
□ 위기 전화번호 (1577-0199, 1393) 알고 있나?
□ 안전 계획이 있나?
```

```
□ 7-8시간 수면
□ 세끼 식사
□ 약물 복용 (필요시)
□ 운동 또는 활동
□ 사회적 접촉
□ 마음챙김 연습
□ 즐거운 활동 하나
```
