# 인지행동치료(CBT) 한국어 매뉴얼

## 개요

인지행동치료(Cognitive Behavioral Therapy, CBT)는 생각, 감정, 행동 간의 상호작용을 이해하고, 부정적인 사고 패턴을 변화시켜 감정과 행동을 개선하는 치료 접근법입니다.

## 핵심 원리

### 1. 인지 모델 (Cognitive Model)

**기본 전제**
- 상황 자체가 아니라 상황에 대한 해석이 감정을 결정합니다
- 부정적 사고는 우울, 불안 등의 정서적 문제를 유발하고 유지합니다
- 사고 패턴을 변화시키면 감정과 행동도 변화합니다

**인지 삼각형**
```
     생각(Thoughts)
      /           \
   /               \
감정(Feelings) - 행동(Behaviors)
```

### 2. 자동적 사고 (Automatic Thoughts)

**정의**
특정 상황에서 자동적으로 떠오르는 생각으로, 대개 의식하지 못하고 지나갑니다.

**특징**
- 빠르고 순간적
- 타당성 여부와 관계없이 즉각 믿음
- 습관적이고 반복적
- 감정에 강한 영향

**한국인의 자동적 사고 예시**
- "다른 사람들이 나를 어떻게 생각할까?" (체면 관련)
- "부모님을 실망시키면 안 돼" (효 문화)
- "나만 뒤처지는 것 같아" (경쟁 문화)
- "모두가 나보다 잘하는 것 같아" (비교 의식)

### 3. 인지 왜곡 (Cognitive Distortions)

**주요 인지 왜곡 유형**

1. **전부 아니면 전무 사고 (All-or-Nothing Thinking)**
   - 예: "완벽하지 않으면 실패다"
   - 한국 문화적 예: "1등 아니면 의미 없다"

2. **과잉 일반화 (Overgeneralization)**
   - 예: "이번에 실패했으니 앞으로도 계속 실패할 것이다"
   - 한국 문화적 예: "한 번 시험을 망쳤으니 인생이 끝났다"

3. **정신적 여과 (Mental Filter)**
   - 긍정적 측면은 무시하고 부정적 측면만 주목
   - 예: "칭찬 100번보다 비판 1번이 더 기억난다"

4. **긍정적 측면 할인 (Disqualifying the Positive)**
   - 예: "성공은 운이었을 뿐이야"

5. **성급한 결론 (Jumping to Conclusions)**
   - **마음 읽기**: "저 사람은 분명 나를 싫어할 거야"
   - **예언**: "면접에서 떨어질 게 뻔해"

6. **확대와 축소 (Magnification and Minimization)**
   - 실패는 확대하고 성공은 축소
   - 예: "작은 실수도 큰 재앙으로 느껴진다"

7. **감정적 추론 (Emotional Reasoning)**
   - 예: "불안하니까 위험한 게 틀림없어"

8. **당위적 사고 (Should Statements)**
   - 예: "나는 반드시 ~해야 한다"
   - 한국 문화적 예: "착한 아들/딸이 되어야 한다"

9. **명명하기 (Labeling)**
   - 예: "나는 실패자야", "나는 쓸모없는 사람이야"

10. **개인화 (Personalization)**
    - 예: "팀 프로젝트가 실패한 건 다 내 잘못이야"

## CBT 치료 과정

### 1. 문제 규명 (Problem Identification)

**목표 설정**
- 구체적이고 측정 가능한 목표
- 예: "우울감 감소", "불안 관리", "수면 개선"

**문제 목록 작성**
- 현재 가장 힘든 문제 3-5개 나열
- 우선순위 정하기

### 2. 사고 기록 (Thought Record)

**5단계 사고 기록표**

```
1. 상황: 언제, 어디서, 무엇을, 누구와?
2. 감정: 어떤 감정을 느꼈나? (0-100%)
3. 자동적 사고: 그때 어떤 생각이 들었나?
4. 증거: 이 생각을 뒷받침하는/반박하는 증거는?
5. 균형잡힌 생각: 더 현실적이고 균형잡힌 생각은?
```

**예시 (한국 직장인)**
```
상황: 회의에서 내 의견을 말했는데 팀장이 무표정했음
감정: 불안 80%, 부끄러움 70%
자동적 사고: "팀장이 내 의견을 바보같다고 생각했을 거야"
증거 찬성: 표정이 무표정이었음
증거 반대: 명시적으로 비판하지 않았음, 다른 사람 의견에도 비슷한 반응
균형잡힌 생각: "팀장은 원래 표정이 무덤덤하다. 내 의견에 대해 생각 중이었을 수도"
```

### 3. 인지 재구성 (Cognitive Restructuring)

**소크라테스식 질문법**

1. **증거 탐색**
   - "이 생각을 뒷받침하는 증거는?"
   - "이 생각에 반대하는 증거는?"

2. **대안적 설명**
   - "다른 설명이 가능할까?"
   - "친구가 같은 상황이라면 뭐라고 조언할까?"

3. **최악의 시나리오**
   - "최악의 경우는 무엇일까?"
   - "그렇게 되면 어떻게 대처할 수 있을까?"

4. **인지 왜곡 확인**
   - "어떤 인지 왜곡을 하고 있나?"

**한국 문화 맥락 질문**
- "체면이나 남의 시선을 너무 의식하고 있지는 않나?"
- "완벽해야 한다는 생각이 도움이 되나?"
- "다른 사람과 비교하는 것이 나에게 어떤 영향을 주나?"

### 4. 행동 활성화 (Behavioral Activation)

**활동 계획표**

우울할 때는 활동이 줄어들고, 활동이 줄면 더 우울해지는 악순환이 생깁니다.

**즐거움과 성취감 활동 계획**

| 시간 | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
|------|----|----|----|----|----|----|-----|
| 아침 | 산책(즐) | 요가(성) | | | | | |
| 오후 | | 독서(즐) | 청소(성) | | | | |
| 저녁 | 친구 전화(즐) | | | 요리(성+즐) | | | |

즐: 즐거움, 성: 성취감

**한국 문화 맞춤 활동**
- 전통 활동: 서예, 다도, 템플스테이
- 사회적 활동: 독서모임, 등산동호회
- 가족 활동: 부모님과 산책, 가족 식사

### 5. 노출 치료 (Exposure Therapy)

**불안 위계 구성**

피하던 상황에 점진적으로 노출하여 불안을 극복합니다.

**예: 사회불안**
```
1단계 (불안 20): 편의점에서 물건 사기
2단계 (불안 30): 카페에서 주문하기
3단계 (불안 50): 친한 친구와 점심 먹기
4단계 (불안 70): 소규모 모임 참석
5단계 (불안 90): 회의에서 발표하기
```

## 한국 문화 맥락 CBT

### 1. 집단주의 문화 고려

**가족 중심 사고**
- "가족을 위해 희생해야 한다"는 생각 검토
- 자기 돌봄과 가족 돌봄의 균형

**관계 중심**
- "화합"과 "눈치"의 긍정적·부정적 측면
- 건강한 경계 설정

### 2. 체면 문화

**체면 관련 자동적 사고**
- "창피하면 어떡하지"
- "다른 사람들이 뭐라고 할까"

**재구성 예시**
- "모든 사람이 나에게 관심 있는 것은 아니다"
- "실수는 인간적이고 자연스러운 것"
- "내 가치는 타인의 평가로 결정되지 않는다"

### 3. 성취 압박

**학업·직장 스트레스**
- "1등 해야 한다"
- "명문대 가야 한다"
- "대기업 다녀야 한다"

**재구성**
- "성공의 기준은 다양하다"
- "과정도 결과만큼 중요하다"
- "나만의 속도로 가도 괜찮다"

## CBT 기법 및 도구

### 1. 호흡 훈련

**복식 호흡 (4-7-8 기법)**
1. 4초 동안 코로 들이마시기
2. 7초 동안 숨 참기
3. 8초 동안 입으로 내쉬기
4. 4회 반복

### 2. 점진적 근육 이완

발끝부터 머리까지 각 근육을 긴장시켰다가 이완

### 3. 활동 일정표

매일의 활동을 기록하고 즐거움(P)과 성취감(M) 평가

### 4. 문제 해결 단계

1. 문제 정의
2. 해결책 브레인스토밍
3. 장단점 평가
4. 해결책 선택 및 실행
5. 결과 평가

## 우울증에 대한 CBT

### 핵심 개입

1. **부정적 인지 삼제 도전**
   - 자기에 대한 부정적 견해
   - 세상에 대한 부정적 견해
   - 미래에 대한 부정적 견해

2. **행동 활성화 강조**
   - 기분이 나아질 때까지 기다리지 말고 먼저 행동

3. **수면 위생 개선**

4. **사회적 지지 활용**

### 한국인 우울증 특징

- 신체 증상 호소 (두통, 소화불량)
- 감정 표현 억제
- "힘내세요" 등 단순 격려의 역효과
- 가족에게 짐이 된다는 죄책감

## 불안장애에 대한 CBT

### 핵심 개입

1. **재앙화 사고 수정**
   - "최악의 경우 vs 가장 현실적인 경우"

2. **안전 행동 줄이기**
   - 회피 패턴 파악 및 점진적 노출

3. **신체 감각 재해석**
   - 불안 증상을 위험 신호가 아닌 불편함으로 인식

### 한국인 불안 특징

- 과도한 걱정 (부모, 자녀, 직장)
- 관계 불안 (눈치, 거절 두려움)
- 미래 불안 (노후, 실직)

## 치료 종결 및 재발 방지

### 1. 치료 성과 정리

- 배운 기술 목록화
- 변화 정리

### 2. 재발 방지 계획

**경고 신호 인식**
- 초기 증상 파악
- 대처 전략 준비

**정기적 점검**
- 월 1회 자가 점검
- 필요시 부스터 세션

### 3. 자기 치료자 되기

- CBT 기술 일상화
- 지속적 연습
