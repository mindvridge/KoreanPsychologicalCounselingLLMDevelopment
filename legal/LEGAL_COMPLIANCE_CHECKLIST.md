## 1. 의료기기법 준수

### 1.1 의료기기 해당 여부 검토

#### ✅ 체크리스트

- [ ] **서비스가 의료기기에 해당하는가?**
  - 의료기기법 제2조: "사람이나 동물에게 단독 또는 조합하여 사용되는 기구·기계·장치·재료·소프트웨어 또는 이와 유사한 제품"
  - **검토 필요 항목**:
    1. 질병의 진단, 치료, 경감, 처치 또는 예방 목적인가?
    2. 상해 또는 장애의 진단, 치료, 경감 또는 보정 목적인가?
    3. 구조 또는 기능의 검사, 대체 또는 변형 목적인가?
    4. 임신조절 목적인가?

- [ ] **현재 서비스의 목적과 기능**
  - ✅ 정서적 지원 및 일반적인 정보 제공
  - ✅ 비의료적 상담
  - ❌ 질병의 진단 또는 치료 (제공하지 않음)
  - ❌ 의학적 조언 (제공하지 않음)

#### 📝 결론 (법률 자문 필요)

**예비 판단**: 본 서비스는 질병의 진단·치료·예방 목적이 아니므로 의료기기에 해당하지 않을 가능성이 높음

**⚠️ 중요**:
- 식품의약품안전처 또는 전문 변호사의 정식 검토 필요
- 서비스 내용이 변경되는 경우 재검토 필요
- 검토 결과 문서화 및 보관

#### 🔧 필요 조치

- [ ] 식품의약품안전처에 서비스 내용 설명 및 문의
- [ ] 의료기기법 전문 변호사 자문
- [ ] 검토 결과 문서 작성 및 보관
- [ ] 서비스에 명확한 고지사항 표시

### 1.2 의료기기가 아님을 명확히 표시

#### ✅ 체크리스트

- [ ] **서비스 이용 전 고지**
  ```
  "본 서비스는 의료기기가 아니며,
   의료법상 의료행위에 해당하지 않습니다."
  ```

- [ ] **의료행위 대체 불가 고지**
  ```
  "본 서비스는 전문적인 의료 상담, 진단,
   치료를 대체할 수 없습니다."
  ```

- [ ] **전문가 상담 권고**
  ```
  "심각한 정신건강 문제가 있는 경우,
   반드시 의료 전문가와 상담하세요."
  ```

#### 📍 표시 위치

- [ ] 첫 화면(홈페이지) 상단
- [ ] 이용약관
- [ ] 서비스 시작 전 팝업
- [ ] 채팅 화면 하단
- [ ] 피드백 화면

## 3. 개인정보보호법 (PIPA) 준수

### 3.1 개인정보 수집 및 이용

#### ✅ 수집 단계 체크리스트

- [ ] **동의 획득**
  - [ ] 개인정보 수집·이용 동의서 제공
  - [ ] 명확하고 이해하기 쉬운 언어 사용
  - [ ] 동의 전 충분한 설명
  - [ ] 동의 거부권 고지
  - [ ] 동의 거부 시 불이익 고지

- [ ] **수집 목적 명시**
  - [ ] 서비스 제공
  - [ ] 서비스 개선
  - [ ] AI 학습
  - [ ] 통계 분석

- [ ] **수집 항목 명시**
  - [ ] 필수 항목 명시
  - [ ] 선택 항목 명시
  - [ ] 민감정보(대화 내용) 별도 동의

- [ ] **보유 기간 명시**
  - [ ] 각 항목별 보유 기간
  - [ ] 파기 방법
  - [ ] 이용자 삭제 요청 방법

#### 📝 필수 동의서 항목

```
□ (필수) 서비스 이용을 위한 개인정보 수집·이용 동의
□ (필수) 민감정보(대화 내용) 수집·이용 동의
□ (선택) 서비스 개선을 위한 정보 활용 동의
□ (선택) 마케팅 정보 수신 동의
```

---

### 3.2 민감정보 처리 (특별 보호)

#### ⚠️ 민감정보 정의

개인정보보호법 제23조:
- 사상·신념
- 노동조합·정당의 가입·탈퇴
- 정치적 견해
- **건강, 성생활 등에 관한 정보**
- 유전정보, 범죄경력 등

**심리상담 대화 내용은 "건강에 관한 정보"로 민감정보에 해당할 수 있음**

#### ✅ 민감정보 체크리스트

- [ ] **별도 동의 획득**
  - [ ] 일반 개인정보와 구분된 동의
  - [ ] 명시적이고 개별적인 동의
  - [ ] 거부권 고지

- [ ] **암호화 저장**
  - [ ] 데이터베이스 암호화
  - [ ] 전송 시 암호화 (HTTPS/TLS)
  - [ ] 백업 데이터 암호화

- [ ] **접근 권한 제한**
  - [ ] 최소 권한 원칙
  - [ ] 담당자 지정
  - [ ] 접근 로그 기록

- [ ] **파기 절차 강화**
  - [ ] 복구 불가능한 방법으로 파기
  - [ ] 파기 기록 유지

---

### 3.3 정보주체의 권리 보장

#### ✅ 체크리스트

- [ ] **열람권**
  - [ ] 이용자가 자신의 정보를 열람할 수 있는 기능

- [ ] **처리정지 요구권**

  - [ ] 정당한 사유 검토
  - [ ] 10일 이내 조치

- [ ] **동의 철회권**
  - [ ] 언제든지 동의 철회 가능
  - [ ] 동의만큼 쉬운 철회 방법 제공

#### 🔧 구현 필요 기능

- [ ] "내 정보 관리" 페이지
- [ ] "대화 기록 삭제" 버튼
- [ ] "계정 삭제" 기능
- [ ] "동의 철회" 옵션
